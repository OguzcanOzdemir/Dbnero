Database backups you can actually restore.

dbnero backs up PostgreSQL, MySQL and SQL Server databases with their own tools, keeps every backup with a checksum and a schema snapshot, restores safely and shows what changed. Free for Windows, macOS and Linux.

Each database gets its own backup file, filed by engine, server, database and date: postgresql/db_5432/crm/2026/11/2026-11-11_204000_postgresql_crm_7b9cde3d.dump Next to it: a manifest with its details, a copy of the table structure and a SHA-256 checksum.

Features

Everything a backup needs, nothing it doesn't

Backups on a schedule

Every night, on chosen days or every few hours, even while dbnero is closed. Keep the last few and older ones are removed for you. Each database gets its own file.

Verified, never half-written

Backups are written to a temporary file, checked with the engine's own tools, then moved into place with a SHA-256 checksum.

Restores that ask first

Pick the database to restore into, or name a new one. Replacing an existing database needs a clear confirmation, and dbnero takes a safety backup first.

See what changed

Compare a backup with the live database, or two backups: tables, columns, keys, indexes, views and which rows are only on one side or different. Comparing never changes either database.

Passwords stay in your keychain

Saved passwords live in the operating system's keychain. They never reach the catalog, the logs or a command line.

A portable archive

A plain folder of files with a manifest next to each backup. Move it anywhere; dbnero can rebuild its list from the manifests.

Restore

Checks before anything is touched

Before a restore starts, dbnero confirms the engine and version match, the checksum is intact, the tools are installed and the target name is free.

  • Same-engine restores only
  • Schema compared with the backup afterwards
  • Clear warning that a restore is not a transaction

Compare

Row-level differences, not guesses

To compare data, the backup is restored into a temporary database, matched row by row on its primary key, and dropped again. Tables without a key get an order-independent fingerprint.

  • Export as HTML, JSON or CSV
  • Sample rows only with your consent

Nothing else to install

The PostgreSQL and MySQL client tools (pg_dump, pg_restore, mysqldump, mysql) are included. SQL Server uses the ODBC driver built into Windows; on macOS and Linux install Microsoft ODBC Driver 18 if you back up SQL Server.

Verify your download

Every release lists SHA-256 checksums in SHA256SUMS.txt. Older versions are on the releases page.
